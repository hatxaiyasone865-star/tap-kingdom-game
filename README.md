# Tap Kingdom

A simple touch-friendly clicker game designed for quick browser play and TikTok-style recording.

## Features
- Tap-to-earn gameplay
- Auto click upgrades
- Combo and progress leveling
- Full-screen mobile friendly layout
- Works in a browser with no install needed

## Run locally
Open `index.html` in a browser.

## GitHub Pages option
If you want to publish it online, you can push this repository to GitHub and enable GitHub Pages.

## Notes
This is a lightweight demo game intended for TikTok recording and prototype testing.
